# Version 5: transport definition and verification protocol

This is a synthetic numerical verification experiment, not a calibrated river forecast. The manuscript and version-1 outputs do not describe this revised method. No field data are claimed.

## Common physical problem

The transported quantity C is depth-integrated tracer surface density in kg/m². In local coordinates x∈[0,L], y∈[0,W], time in seconds,

`C_t + u C_x = D (C_xx + C_yy)`.

u≥0 is uniform longitudinal velocity in m/s; lateral velocity is zero; D≥0 is uniform dispersion in m²/s. Flux is `J=(u C-D C_x, -D C_y)`.

- Inlet: C(0,y,t)=0 (clean incoming water). This is NOT zero total flux: upstream diffusive loss is allowed and accounted for.
- Outlet: C_x(L,y,t)=0, with advective export u C.
- Side walls: C_y=0.
- Initial condition: the same prescribed smooth compact pulse for both methods, defined in `config.initial_normalized`, amplitude 0.001 kg/m². It is not generated by the neural network.

Domain, pulse, coefficients, horizon and boundary identifiers travel together in an immutable Experiment. A checkpoint's physical signature must match. Latitude/longitude never enter the network as arbitrary metre offsets. Scenario names denote synthetic parameter choices, not observed topography.

All scenarios use L=1000 m and T=300 s. Terrain selects W and fixed Q_base, Manning n and slope S. Season scales Q only by 0.7, 1 or 1.3. For the wide rectangular approximation, `h=(Q*n/(W*sqrt(S)))^(3/5)`, `u=Q/(W*h)`, `D=0.08*u*h`. There is no independent output-amplitude scaling. Constants reside in config.py. These hydraulics are simplifying assumptions, not independently validated hydrodynamics.

## Conservative reference

Cell-centred finite volumes use first-order upwind advection and central diffusive face fluxes. The inlet face is half a cell from the first centre; therefore `J_left=-2 D C_first/dx`. The outlet face flux is `u C_last`. Interior face fluxes cancel exactly in the domain sum.

The explicit timestep satisfies
`dt * (u/dx + D*(3/dx²+2/dy²)) <= 0.8`.
The factor 3 includes the inlet half-cell diffusion contribution. This sufficient nonnegative-coefficient bound combines advection and diffusion. The solver rejects invalid inputs, never clips negative results, and exports integrated flux from both ends. It reports `M(t)+export(t)-M(0)` in kg and relative to prescribed initial mass. Numerical precision conservation is tested. First-order upwind advection has numerical diffusion; resolution comparisons are required and reported, not hidden.

## Hybrid neural surrogate

Inputs are dimensionless `(xi,eta,tau,a,bx,by)`, with `a=uT/L`, `bx=DT/L²`, `by=DT/W²`. The network uses seven documented features, three 64-unit Tanh layers and a Softplus output. A bounded coordinate transform has zero derivative at both longitudinal ends; a cosine transverse feature has zero wall derivatives. The longitudinal boundary layer uses dimensionless scale `e=clip(bx/a,1e-5,0.02)`. Multiplication by `(1-exp(-xi/e)-xi*exp(-1/e)/e)/(1-exp(-1/e)-exp(-1/e)/e)` enforces zero inlet concentration, retains positivity, and preserves the zero outlet derivative. Automatic differentiation tests verify these conditions to floating-point tolerance.

Interior PDE, initial-condition and integrated mass-balance losses are SOFT constraints. They do not establish exact conservation or accuracy. Boundary and positivity construction must not be described as proof of all PDE constraints.

Training is explicitly hybrid: numerical supervision on a 400×48 reference grid plus physics losses. It is not data-free PINN training. A fixed label-generation seed selects 60000 points per scenario from 61 times; each training seed splits labels 90/10. The separate reported reference uses 800×92 cells, restricted by cell averaging to the 200×23 output grid. These intentional grid differences are for resolution verification, not inconsistent physical parameters.

Adam is followed by a fixed-budget L-BFGS refinement. The hybrid refinement also supervises integrated mass at six times for each of the twelve scenarios, using the same numerical teacher. This is explicit additional supervision, not an inference-time correction. Metadata records the optimizer schedule, weights, counts, seeds, refinement evaluations and elapsed time. Data-only comparators use the same architecture (including positivity and boundary transforms), same seed, same pointwise labels, same minibatches and same optimization budget; soft physics/initial/mass losses and integral mass supervision are removed. This is a comparison of the complete hybrid formulation against pointwise-data training, not an isolated PDE-term ablation or an unconstrained arbitrary black box.

Only the twelve trained physical configurations are supported. The original supported-case experiment alone does not demonstrate generalization to unseen hydraulic parameters; the separate frozen interpolation audits below address a bounded extension. Training loss and held-out numerical-label error are diagnostics; neither is a substitute for the independent report.

## Acceptance and reporting

Predetermined numerical checks are nonnegative density, space–time relative L2 error below 10%, initial-field relative L2 below 5%, maximum mass-budget error below 2%, and reference conservation below 1e-10. Each result records each check separately. Failed results remain in output and the UI displays the failure. These tolerances are engineering acceptance criteria for this synthetic exercise, not journal standards or field-validation criteria.

The network budget integrates its actual learned flux, including any finite-precision boundary discrepancy; no concentration rescaling is used to force conservation. Its spatial midpoint and temporal trapezoidal quadratures are approximate, unlike the step-by-step FVM budget. Error and initial-mass mismatch are reported separately.

Runtime benchmarks use the same output grid/time samples for both methods, one warm-up, ten repetitions, alternating order, already-loaded CPU models, and recorded thread count. They exclude training and include coordinate construction/inference or the numerical rollout. No speed advantage is assumed.

Residual intervals use an explicitly chronological calibration/evaluation split and report empirical coverage. They are descriptive numerical residual intervals, not distribution-free conformal or field-prediction guarantees. Field CSV validation requires registered local metres, seconds and kg/m²; no stretching of observation coordinates or clipping of timestamps is permitted. Independent-row bootstrap assumptions are disclosed.

## Development and evaluation scope

Pilot diagnostics on these synthetic configurations informed architecture development. The finer numerical reference is independent in resolution, not a blinded external test dataset. The three-seed comparison measures repeatability on the supported configurations; it does not establish out-of-distribution performance.

Mass monotonicity is reported as the largest positive increment in domain-integrated mass between successive output times, divided by the prescribed initial mass. Zero means nonincreasing at the sampled times. It is distinct from nonnegative concentration and does not mean a moving plume is pointwise monotone in space or time. No unexplained monotonicity pass label is used.

Checkpoint metadata contains the shared hybrid weight/sampling profile. For `variant=data_only`, only the data loss is applied; the recorded hybrid PDE/IC/boundary/mass weights are inactive. The variant and executable loss branches determine the effective objective. Adam uses equal iteration counts, and L-BFGS uses equal maximum iteration budgets; line searches may produce different closure counts and wall times, which are recorded.


## Extended frozen-checkpoint audit

The additional protocol in outputs/extended_verification_v5 was written before evaluating eight unseen hydraulic configurations (Q/Q_base=0.85 and 1.15, each of four terrains). No checkpoints were retrained, selected or altered. All 24 hybrid evaluations across three seeds passed the declared criteria; maximum space-time L2 was 1.6701% and mass-budget error was 0.7343%. All 24 comparator evaluations also passed. This supports tested interpolation along the specified discharge-to-hydraulics relationship, not arbitrary combinations, unseen initial fields or extrapolation. The ordinary inference guard remains unchanged in scope; research=True is explicitly restricted to hydraulic interpolation within each terrain's trained bounds.

An independent analytical advection-diffusion eigenmode, satisfying the same boundary types, tests the numerical solver with a different prescribed initial field. Errors decrease from 0.4547% at 20x10 cells to 0.05929% at 160x80, consistent with first-order spatial convergence. Fixed-grid timestep refinement approaches a spatial-error floor. A baseline final-time 1600x184 reference comparison finds 2.5142% relative difference from the restricted 800x92 reference. This remaining reference uncertainty must accompany accuracy claims; finest self-error zero does not establish an exact solution.

A 600-second reference-only rollout retains positivity and conservation at floating-point precision. The neural model remains restricted to 300 seconds; no longer-horizon neural validation is claimed. Residual intervals now expose the empirical coverage gap and an explicit undercoverage flag; the UI warns when nominal coverage is not met. This is diagnosis, not a new calibrated interval method.

The original verification_v5 source hashes describe the earlier executed report. Later audit changes are captured separately in the extended audit's final source snapshot. The architecture, parameters and saved weights were not changed by this extended audit.
